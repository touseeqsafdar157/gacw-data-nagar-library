# Govt Associate College Data Nagar Library - Frontend

React + TypeScript + Material-UI Frontend for College Library Management System.

## Features
- **Student & Public Portal**: OPAC Book Search, DDC Shelves, 60-Desk Study Hall live booking, BISE Past Papers, Book Suggestions, Patron Borrow History.
- **Librarian Circulation Desk**: Fast Book Issue/Return, Barcode generation, Fine Management, Almari/Cupboard rack arrangement.
- **Principal & Admin Dashboard**: College oversight, Real-time analytics, Procurement approval.

## Installation & Running

```bash
# Install dependencies
npm install

# Run frontend development server
npm run dev

# Build for production
npm run build
```
